This repo contains Data Science code snippet.

## Codalyze landing page

The repository includes a static marketing site for Codalyze (`index.html` with `styles.css` and
`script.js`). To run it locally, start a simple web server from the repo root and open the page in
your browser.

```bash
cd /workspace/Data-Science
python -m http.server 8000
```

Then visit http://localhost:8000/index.html.
